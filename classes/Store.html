    ProtectedopenWithObjectStore

    • openWithObjectStore(): Promise<IDBDatabase>

      Opening without a version attaches to an existing database at whatever version it already has, so a database created by another connection is never rejected for having the "wrong" version. The object store is then added with the smallest possible version bump, which leaves any object stores belonging to other connections intact.

      Runs the given request factory inside a transaction on the object store and resolves with its result.

      A connection that closes after the transaction has already started aborts it, which Store.openObjectStore cannot see coming, so retry that once on a fresh connection. An aborted transaction rolls back, so the retry cannot apply a write twice.

    ProtectedyieldOnConnectionLoss

    • yieldOnConnectionLoss(
          database: IDBDatabase,
          attempt: Promise<IDBDatabase>,
      ): IDBDatabase

      Watches for the two ways a cached connection stops being usable, dropping it from the cache so that the next operation transparently reopens:

      • versionchange: another connection wants to upgrade or delete the database and is blocked until every other connection closes, so close as soon as it asks. An explicit close() does not fire close, hence forgetting here too.
      • close: the browser closed the connection on its own, which it does when tearing down the page or when the storage backing the database goes away.

      Parameters

      • database: IDBDatabase
      • attempt: Promise<IDBDatabase>

        The cache entry this connection belongs to.

      Returns IDBDatabase
