    ProtectedopenWithObjectStore

    • openWithObjectStore(): Promise<IDBDatabase>

      Opening without a version attaches to an existing database at whatever version it already has, so a database created by another connection is never rejected for having the "wrong" version. The object store is then added with the smallest possible version bump, which leaves any object stores belonging to other connections intact.
